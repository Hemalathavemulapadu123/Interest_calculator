# Simple Interest Calculator

A simple and user-friendly web application built using Python and Streamlit to calculate Simple Interest and the Total Amount.

## Features

* Calculate Simple Interest
* Calculate Total Amount
* Easy-to-use interface
* Fast and accurate calculations

## Technologies Used

* Python
* Streamlit

## Formula

Simple Interest:

**SI = (P × R × T) / 100**

Where:

* P = Principal Amount
* R = Rate of Interest
* T = Time in Years

Total Amount:

**Total Amount = Principal Amount + Simple Interest**

## How to Run

1. Install Python on your computer.
2. Install Streamlit.
3. Download or clone this repository.
4. Open the project folder.
5. Run the Streamlit application.

## Example

If:

* Principal Amount = ₹1,00,000
* Rate of Interest = 10%
* Time = 2 years

Then:

* Simple Interest = ₹20,000
* Total Amount = ₹1,20,000
